# TypeScript task example

Node.js with TypeScript and ESM. Requires Node.js 22.18 or newer.

- `src/interfaces/task.ts` and `user.ts`: Task and User interfaces.
- `src/tasks.ts`: async functions to create and complete a task.
- `src/index.ts`: examples using `await` and `try/catch` for success and failure.

Tasks are kept in an array and disappear when the program stops. There are no HTTP routes.

Run the example:

```sh
npm install
npm run build
npm start
```

`dist` contains JavaScript generated by the build. Interface files look empty there because TypeScript removes interfaces during compilation. Edit the files in `src`.

## Strict mode and npm scripts

TypeScript strict mode is enabled with `"strict": true` in `tsconfig.json`.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Run TypeScript and restart when source files change. |
| `npm run typecheck` | Check types without generating JavaScript. |
| `npm run build` | Compile TypeScript into `dist`. |
| `npm start` | Run the compiled example. |

## Verification

```sh
npm run typecheck
npm run build
npm start
```

The example prints a created task, a completed task, and `Operation failed: Task not found.` The final message demonstrates a deliberately missing task being handled by `catch`.
